# はてなブログ用テンプレート

はてなブログに投稿する記事のテンプレート集です。Markdownモードでの執筆を前提にしています。

## はてなブログ固有の仕様メモ

- **Frontmatter は不要**（タイトル・カテゴリ・公開設定はWeb UIで設定）
- **Markdownモード必須**：管理画面の「設定 → 編集モード」で「Markdownモード」を選択しておく
- **見出し**：h1〜h6 すべて使えるが、テーマによって h3 が大見出し扱いになる場合あり
  - 本テンプレートでは Qiita 同様 h1（タイトル）+ h2/h3 中心
- **独自記法（Markdownモードでも使える）**：
  - **目次**：`[:contents]` を本文中に1行で書くと自動生成（前後に空行が必要）
  - **脚注**：`((脚注の内容))` で文中に挿入できる（Markdown標準の `[^1]` も使えるが、はてな記法のほうが安定）
  - **HTMLは混在可**：装飾やレイアウト調整に `<div>`, `<details>` などを直接書ける（前後に空行が必要）
- **コードブロック**：シンタックスハイライト対応（` ```python ` のように言語指定可）
- 投稿手段：Web UI / AtomPub API（はてなブログAPIでプログラムから投稿可能）

## 読者層と書き方の傾向

はてなブログは **はてなブックマーク連携で「バズる」可能性が3媒体（Qiita/Zenn/note）と並んで強い** プラットフォームです。技術系の記事でも、ストーリー・体験・主張が混ざった「ブログらしい」書き方が読まれやすい傾向があります。

- **Qiitaの硬さ × noteの柔らかさ**の中間くらいの文体が合う
- **タイトルで主張を出す** とブクマされやすい（「○○は△△だと思う」「○○を半年使ってわかったこと」）
- **目次（`[:contents]`）を必ず置く**（長文記事が多く、目次が読者の意思決定を助ける）

## 使い方

1. ジャンルに合ったファイルをコピー
2. プレースホルダーを実内容に置き換える
3. はてなブログ管理画面の Markdown モードで新規記事を作成し、貼り付ける
4. カテゴリ・公開設定・アイキャッチを設定して公開
