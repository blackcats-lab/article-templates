# 生成AI利用時の注意書きスニペット

生成AIで記事を執筆した場合は、「はじめに」セクションの直下に注意書きを入れます。媒体ごとに使える記法が違うので、コピペで使えるよう用意しています。

## Qiita

```
:::note info
当記事は生成AIによって執筆しています。内容の正確性には十分注意を払っていますが、誤った情報が含まれている可能性があります。実際にご利用の際は、公式ドキュメント等もあわせてご確認ください。
:::
```

## Zenn

```
:::message
当記事は生成AIによって執筆しています。内容の正確性には十分注意を払っていますが、誤った情報が含まれている可能性があります。実際にご利用の際は、公式ドキュメント等もあわせてご確認ください。
:::
```

## note

noteには注釈ボックスの独自記法がないため、引用ブロックで代替します。

```
> **生成AIによる執筆について**
> 当記事は生成AIによって執筆しています。内容の正確性には十分注意を払っていますが、誤った情報が含まれている可能性があります。実際にご利用の際は、公式ドキュメント等もあわせてご確認ください。
```

## バリエーション

「人による加筆・修正済み」であることを伝えたい場合：

```
当記事は生成AIによる下書きを元に、筆者が加筆・修正を行っています。技術的な内容については筆者自身で動作確認していますが、誤りに気づかれた方はコメント等でご指摘いただけると助かります。
```

「全文AI生成」を明示する場合：

```
当記事は生成AIによって執筆されており、筆者による事実確認は限定的です。あくまで参考情報として読み、実装や判断の際は必ず公式ドキュメントをご確認ください。
```
