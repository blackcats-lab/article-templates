# note用テンプレート

note（note.com）に投稿する記事のテンプレート集です。Qiita版をベースに、noteの仕様と読者層に合わせて再設計しています。

## note固有の仕様メモ

- **Frontmatter は不要**（タイトル・タグ・サムネイルはWeb UIで設定）
- **見出しは h2（`##`）と h3（`###`）のみ**
  - `#`はタイトル扱い
  - `####`以降は自動的に h3 に変換される
  - → このテンプレートでは原則 h2／h3 で構成している
- **`:::note info` 等の独自記法は使えない**
  - 注意喚起は引用ブロック（`>`）か太字で代替
- 使えるMarkdown：
  - 見出し（h2/h3）、太字、リンク、画像、リスト、引用、コードブロック、区切り線
  - コードブロックは言語名を書いてもシンタックスハイライトは付かないが、貼っておくと他媒体への流用が楽
- **目次が自動生成される**（PCのみ）：h2/h3 の設計が目次品質に直結する

## noteの読者を意識した書き方の違い

技術記事と思って書くと、note では刺さりません。Qiita / Zenn と比べて以下を意識します。

- **読者は開発者だけではない**：略語の初出は正式名称を添える、専門用語に短い補足
- **個人の体験・動機・感情を厚く**：「何を作ったか」より「なぜ作ったか／どんな気持ちだったか」
- **タイトルは検索より共感**：「Next.js + Supabase でタスク管理アプリを作った」より、「会社で使うツールがどれもしっくり来なくて、自分で作りました」のほうが刺さりやすい
- **コードは少なめに**：ハイライトされないので、重要部分だけ短く

技術記事ジャンル（01〜08）は note ではやや読まれにくいですが、テンプレートとしては全ジャンル用意しています。とくに **09 やってみた** と **10 振り返り** が note で映えます。

## 使い方

1. ジャンルに合ったファイルをコピー
2. プレースホルダーを実内容に置き換える
3. note の Web UI に貼り付ける（Markdownで貼り付け可能）
4. サムネイル画像とハッシュタグを設定して公開
